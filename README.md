## 🌐 Deploying to GitHub & GitHub Pages

To push this repository to GitHub and get a live free website URL:

1. **Initialize Git & Commit**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of Shivam's modern developer portfolio"
   ```

2. **Create a new repository on [GitHub](https://github.com/new)** (e.g. `portfolio` or `<your-username>.github.io`).

3. **Link and Push**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```

4. **Turn on GitHub Pages**:
   - Go to your repository on GitHub.
   - Navigate to **Settings** → **Pages**.
   - Under **Branch**, select `main` and root `/`, then click **Save**.
   - Your portfolio will be live at `https://<your-username>.github.io/portfolio/`!
